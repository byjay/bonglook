# Outlook (데스크톱 메일 클라이언트)

Windows용 **독립 실행 프로그램**입니다. Outlook Add-in을 사용하지 않으므로 회사에서 Add-in을 막아놨어도 동작합니다. PC에 설치된 Outlook / PST 데이터를 읽어 **로컬 DB에 저장·색인**하고, **대화형 메일 검색**, **요약(스케줄/놓친 일)**, **영어·중국어 메일 번역·분석**, **답장 초안 작성**, **첨부파일(PDF·엑셀·이미지·워드) 분석**을 제공합니다.

> 모든 메일·첨부·주소록·분석 결과는 **내 PC 로컬(SQLite DB)** 에만 저장됩니다. 외부로 나가는 것은 분석 요청뿐입니다.

## 주요 기능

### 메일 수집 & 저장
- **PST / Outlook 연동**
  - `Outlook 연동(실시간)`: PC의 Outlook이 열고 있는 데이터를 실시간으로 읽음 → 새 메일 자동 수신
  - `PST 파일 직접`: Outlook을 켜지 않아도 `.pst` 파일을 직접 읽음
- **날짜 필터**: 기본 최근 6개월 / 전체 / 기간 지정
- **실시간 새 메일**: 설정 주기(기본 60초)마다 새 메일 자동 확인 + 시스템 알림
- **동기화**: 받은편지함 + 보낸편지함을 한 번에 스캔 → 로컬 DB 저장 + 색인
  - 스캔하며 **첨부파일(도면 등)을 로컬 폴더에 자동 저장**, 텍스트 자동 추출
  - 발신자 정보로 **주소록 자동 축적**

### 로컬 DB & 색인 (SQLite)
- 모든 메일/첨부/주소록/분석 결과를 SQLite로 DB화
- **FTS5 전문 색인**으로 빠른 검색 — 한국어·영어 정상, 중국어·일본어는 LIKE 폴백
- 언어 자동 판별(ko/en/zh/ja)로 메일마다 언어 태그 부여

### 분석 기능 (Cerebras)
- **요약(브리핑)**: 전체 메일을 훑어 내 스케줄 / 한 일 / 놓친 일 / 누가 언제 무엇을 보냈는지 요약
- **대화형 메일 검색·질의응답**: 자연어로 DB 위에서 대화
- **영어·중국어 메일 번역·분석**: 외국어 메일을 한국어로 번역 + 핵심 요약/의도 분석
- **답장 초안 작성**: 원문 언어에 맞춰 톤·지시사항 반영한 초안 자동 생성
- **첨부파일 분석**: PDF·엑셀·이미지·워드 내용 추출 후 요약/질의
- **5개 API 키 자동 폴백**: 앞 키 실패(401/403/429/5xx) 시 다음 키로 자동 전환

### 관리자 모드 (설정 하단 "관리자 정보 · 진단")
- **앱 버전 / 데이터베이스 상태 / DB 경로 / 전문검색(FTS) 사용 여부 / 저장된 메일 수 / 마지막 동기화 시각** 표시
- **연결 테스트** · **첨부 폴더 열기** · **진단 새로고침** 버튼
- API 키·소스·기간·실시간 주기·최대 메일 수·첨부 자동저장 등 모든 설정을 한 화면에서

## 데이터 아키텍처
- **저장소**: 로컬 SQLite (`%AppData%/outlook-mail-client/mail.db`) + electron-store(설정)
- **테이블**: mails, attachments, contacts, analyses, state (+ FTS5 가상 테이블)
- **첨부**: `%AppData%/outlook-mail-client/attachments/날짜_제목/` 폴더에 원본 저장
- **데이터 흐름**: Outlook COM / PST → sync → db(upsert + FTS 색인) → renderer 표시 → 분석 요청만 Cerebras로

## IPC 구조
- **preload.js**: `window.api.*` 32개 함수 (contextBridge, 격리 모드)
- **main.js**: `ipcMain.handle` 28개 채널 — 전부 `{ok, ...}` 반환, try/catch 가드
- renderer ↔ preload ↔ main 채널 1:1 정합성 검증 완료 (누락/사장 채널 0)

## 설치 & 빌드 (사용자 PC / Windows)
```bash
npm install
npm run rebuild      # better-sqlite3 Electron ABI 리빌드
npm start            # 개발 실행
npm run dist         # NSIS 원클릭 설치 파일(Outlook-Setup-<ver>.exe) 생성
```
- **NSIS 원클릭**: `oneClick:true`, 바탕화면·시작메뉴 바로가기 자동 생성, 사용자 권한 설치(perMachine:false)
- **자동 업데이트**: electron-updater + GitHub Releases (package.json `publish` 에 owner/repo 설정 필요)

> Linux/샌드박스에서는 Windows용 `.exe` 빌드와 실제 Outlook COM 연동 테스트가 불가능합니다. EXE 생성은 Windows PC에서 위 명령으로 진행하세요. UI/로직은 헤드리스 Electron으로 전 화면·전 버튼 검증 완료.
