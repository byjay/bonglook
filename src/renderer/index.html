주소록

Outlook에서 가져오기를 누르거나, 메일 동기화 시 발신자가 자동 축적됩니다.

설정

위에서 고른 제공자의 API 키를 입력하세요(최대 7개). 앞 키가 실패하면 자동으로 다음 키를 사용합니다. 키는 제공자별로 따로 저장되므로 제공자를 바꿔도 기존 키가 지워지지 않습니다.

AI 제공자 (여러 개 등록 · 자동 전환)

제공자를 2개 이상 등록해 두면, 1순위가 막혀도(한도 소진·키 오류·서버 오류) 다음 순위로 자동 전환됩니다. 제공자를 고르면 주소·기본 모델이 자동으로 채워집니다 — 키만 넣으세요. 키는 제공자마다 따로 저장됩니다.

등록한 제공자를 확인하려면 [전체 연결 테스트]를 누르세요.

메일 열면 자동 분석

로컬 저장물 정리

이 앱이 로컬에 저장한 첨부 사본과 오래된 내보내기 파일만 다룹니다. Outlook 원본과 메일 데이터는 절대 건드리지 않습니다. 자동 점검은 업무시간(09~18시) 매시 정각에 별도 프로세스로 돌며 보고만 합니다 — 자동으로 지우는 일은 없습니다.

아직 점검하지 않았습니다.

메일 처리 상태 (할 일 / 보류 / 처리 / 확인)

상태 지정은 메일 우클릭·읽기창 버튼·단축키 1~4(0=해제, Ctrl+Z=되돌리기)로 합니다. 목록 위 색 칩은 보기 필터 전용이며 상태를 바꾸지 않습니다.

프로젝트 분류 범위

기본 분류는 보낸 메일만 대상으로 합니다. 받은 메일은 들어 있는 폴더 이름이 곧 프로젝트이므로, 전체를 다시 분류하면 대시보드의 프로젝트 축이 제대로 채워집니다. (실측: 미분류 '기타' 20,101건 → 1,435건)

프로젝트 활동성 구간

모든 목록은 날짜 최신순이 기본이며, 프로젝트·조직·스레드 같은 그룹은 마지막 활동일 최신순으로 정렬합니다. 아래 기준으로 진행 중인 프로젝트를 항상 위에 둡니다.

AI 답장 언어

“원문 따름”은 상대가 이번에 쓴 새 본문만 보고 판정합니다(아래 인용된 영문 원문은 무시). 지시사항에 “영어로”·“한국어로”라고 적으면 그 지시가 언제나 최우선입니다.

AI 분석 교차 검증

기한·요청 유무·할 일 개수·발신자 의도가 두 결과에서 같으면 "일치" 배지를, 다르면 "확인 필요" 배지와 차이를 표시합니다. 등록된 제공자가 1개뿐이면 자동으로 단일 결과로 동작합니다.

Bmail 도움말

주요 기능

  • 동기화 — Outlook의 받은/보낸편지함과 하위 폴더(설정에 따라 아카이브 PST까지)를 읽어 로컬 DB에 저장·색인합니다.
  • 메일 검색 — "OO가 보낸 OO 관련 메일 찾아줘"처럼 한국어로 물으면 실제 저장된 메일을 근거 목록으로 함께 보여줍니다.
  • 번역/분석 — 선택한 메일을 한국어로 번역하고 요점·마감·액션을 정리합니다.
  • 답장 초안 — 원문 언어에 맞춰 답장 초안을 작성합니다. 지시사항 칸에 요구사항을 적을 수 있습니다.
  • 요약 — 기간(오늘/7일/30일) 내 메일을 종합해 스케줄·처리한 일·놓친 일을 정리합니다.
  • 미회신 경고 — 대시보드에서 받았지만 답장하지 않은 대화를 오래된 순으로 보여줍니다.
  • 주소록 — 동기화할 때 Outlook 연락처와 메일 발신자가 자동으로 축적됩니다.
